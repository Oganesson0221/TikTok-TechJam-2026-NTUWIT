# Official run and iteration logs

`iterations.jsonl` is the audit log. Every record includes the hypothesis, applied diff, official and supplemental metrics, errors, recoveries, and manual-intervention count. `openai_agent_iterations.jsonl` and `openai_agent_summary.json` preserve the six real GPT-5 mini decisions, rationales, reflections, exact API usage, and measured outcomes. `implementation_code_diff.patch` contains the implementation patch.
